学伴 StudyBuddy

给「想自学一门技术却没人带」的人，一个 AI 全程陪练的本地学习台

每日任务打卡 · AI 老师批改作业 · 自动抓教材做教程汇总 · 终端式真机代码练习——全部本地运行、免费 AI 额度，不花一分钱订阅。

▸ 打开在线体验 GitHub 源码

在线体验为只读静态版；完整功能（真机运行 / AI 批改 / 自动汇总）需按下方步骤本地运行。

为什么做它

大学生自学最大的坎不是「缺教程」，而是从看教程到真正动手的那段路没人带：不知道在哪个文件夹写代码、代码怎么存成文件、报错怎么解、计划怎么坚持。学伴把「计划 → 教程 → 练习 → 批改 → 打卡」整条链路收进一个本地网页，并用免费 AI 额度当陪练。

核心功能

自适应学习计划一门技术拆成每天小任务（任务+知识点+教材+编程作业），天数可长可短
AI 老师批改作业贴代码直通 AI 深度批改：完成度/问题/改法/得分，记录可回看
每日教程汇总AI 读当天抓取的教材正文，分节讲解 + 练习题，答案默认隐藏
真机代码练习区跑本机真 Python，traceback 原样显示，报错附中文白话贴士
进度与成就计划日历、阶段完成度、成就墙，交过作业的日期带金色光边
本地 + 免费额度数据存本机，隐私不出门；AI 只用免费额度，零订阅成本

界面一览

部署到你自己的电脑

git clone https://github.com/chenzhongyu331166-hub/study-buddy.git
cd study-buddy
python -m venv venv
venv\Scripts\pip install -r requirements.txt
start.bat        :: 自动打开 http://127.0.0.1:5000
AI 相关功能需要一份模型通道配置（base_url + api_key + model，如魔搭社区免费额度）。 未配置 AI 时，打卡 / 大纲 / 进度 / 代码练习区 仍可正常使用。
