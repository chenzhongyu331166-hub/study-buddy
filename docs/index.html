核心功能

🗓️
自适应学习计划一门技术拆成每天 3 个小任务（任务+知识点+教材+编程作业），天数可长可短（本项目即由 84 天压缩为 27 天）。
📖
每日教程汇总AI 读当天抓取的教材正文，分节讲解 + 练习题（答案默认隐藏），把「自己啃文档」变成「每天读一页被嚼碎的内容」。
🧪
真机代码练习区终端式交互运行，跑本机真 Python；支持运行中继续输入，报错附中文白话贴士。
📝
AI 老师批改完成度 / 问题 / 改法 / 得分，记录可回看，批完一键标记完成。
📂
本地项目 AI 审阅把整个作业文件夹（文件树 + 全部源码 + 当天任务）交给 AI，按需求对照 / 结构 / 问题清单 / 亮点 / 下一步输出。
🏅
激励系统每日弹窗提醒 + 连续打卡 + 进度日历（交过作业带金色光边）+ 成就墙。
📱
手机可用通过隧道在手机浏览器访问，碎片时间也能打卡学习。
🔓
开源可自部署代码开源（MIT），任何人可下载、自建、换自己的 AI key；数据存本地。

真实问题修复
某天没打卡，第二天直接被推到下一课改为缺勤自动顺延：没学的那天往后压，绝不跳天
凌晨 00:02 交的作业被系统判成「第二天」把「今天」的定义改为早 7 点才翻天，贴合学生作息
用户反馈「任务太难、和教程脱节」把当天任务清单喂给 AI，教程汇总必须逐条支撑当天任务，「精读」改为一页嚼碎的汇总

部署到你自己的电脑

git clone https://github.com/chenzhongyu331166-hub/study-buddy.git
cd study-buddy
python -m venv venv
venv\Scripts\pip install -r requirements.txt
start.bat        :: 自动打开 http://127.0.0.1:5000
AI 相关功能需要一份模型通道配置（base_url + api_key + model，如魔搭社区免费额度）。 未配置 AI 时，打卡 / 大纲 / 进度 / 代码练习区 仍可正常使用。
